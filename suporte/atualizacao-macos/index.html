FIORE STORE | Manual de atualização do macOS

Método 1 – Sem pendrive e sem formatação

Este manual ensina como atualizar o sistema operacional do seu Mac utilizando o OpenCore Legacy Patcher, sem precisar de pendrive ou formatar o computador, buscando preservar seus arquivos e aplicativos.

As imagens são referências visuais. O texto de cada etapa indica a opção a selecionar no seu Mac. Para mudanças de geração do macOS, a Dortania recomenda o método com pendrive.

ETAPA 1 – Preparação do Mac

Antes de iniciar:

  • Conecte o Mac ao carregador.

  • Conecte-se a uma rede Wi-Fi.

  • Tenha preferencialmente 50 GB ou mais de espaço livre.

  • Faça um backup dos seus arquivos importantes.

  • Confirme a compatibilidade do equipamento com a FIORE.

ETAPA 2 – Baixar o OpenCore Legacy Patcher

Acesse o link oficial:

🔗 https://github.com/dortania/Opencore-Legacy-Patcher/releases 

Localize a versão indicada pela FIORE e desça a página até encontrar a seção Assets.

  1. Baixe o arquivo OpenCore-Patcher.pkg.

  2. Abra o arquivo baixado.

  3. Clique em Continuar.

  4. Clique em Instalar.

  5. Digite a senha do Mac.

  6. Aguarde a conclusão da instalação.

ETAPA 3 – Atualizar o OpenCore no Mac

  1. Abra o OpenCore Legacy Patcher.

  2. Clique em Build and Install OpenCore.

  3. Aguarde o processamento.

  4. Clique em Install to disk.

  1. Selecione o SSD interno do Mac.

  2. Selecione a partição EFI.

  3. Digite a senha do Mac, caso solicitado.

  4. Clique em Reboot para reiniciar.

9. Reiniciar corretamente pelo OpenCore

9.1 – Segure a tecla Option (Alt)

Assim que o computador começar a reiniciar, mantenha pressionada a tecla Option (Alt) até aparecerem as opções de inicialização.

9.2 – Na primeira tela, selecione EFI Boot

Utilize as setas do teclado para selecionar EFI Boot e pressione Enter.

9.3 – Na segunda tela, selecione Macintosh HD

Após entrar pelo EFI Boot, aparecerá o menu do OpenCore.

Selecione Macintosh HD e pressione Enter.

O Mac deverá iniciar normalmente no macOS Ventura.

Após o Ventura iniciar normalmente, prossiga para a etapa 4.

ETAPA 4 – Baixar o macOS Sonoma

  1. Abra novamente o OpenCore Legacy Patcher.

  2. Clique em Create macOS Installer.

  3. Clique em Download macOS Installer.

  1. Localize o macOS Sonoma 14.

  2. Selecione a versão indicada pela FIORE.

  3. Clique em Download.

  4. Aguarde a conclusão do download e da extração do instalador.

ETAPA 5 – Cancelar a criação do pendrive

Após concluir o download, o OpenCore poderá perguntar se deseja criar um instalador USB.

Clique em No (Não) ou Cancel (Cancelar).

O instalador do macOS Sonoma estará disponível na pasta Aplicativos do seu Mac.

Não será necessário utilizar um pendrive.

ETAPA 6 – Instalar o macOS Sonoma

  1. Abra o Finder.

  2. Entre na pasta Aplicativos.

  3. Localize o aplicativo Instalar macOS Sonoma.

  4. Abra o aplicativo.

  1. Clique em Continuar.

  2. Aceite os termos de instalação.

  1. Selecione o Macintosh HD.

  2. Clique em Instalar ou Continuar.

  3. Digite a senha do Mac, caso solicitado.

  4. Aguarde a preparação da instalação.

Não é necessário formatar ou apagar o SSD do Mac.

ETAPA 7 – Reiniciar segurando Option (Alt)

Quando o computador começar a reiniciar, mantenha pressionada a tecla Option (Alt) até aparecerem as opções de inicialização.

Utilize as setas do teclado para selecionar EFI Boot e pressione Enter.

Não selecione diretamente o Macintosh HD nessa primeira tela.

ETAPA 8 – Selecionar o instalador do macOS Sonoma

8.1 – Após selecionar EFI Boot, aparecerá uma segunda tela.

Nessa tela, procure a opção macOS Installer.

Ilustração para identificar a opção correta.

macOS Installer

Selecione para continuar a instalação do Sonoma.

Macintosh HD

Não selecione enquanto houver a opção específica macOS Installer.

8.2 – Utilize as setas do teclado para selecionar macOS Installer e pressione Enter.

8.3 – Aguarde a instalação do macOS Sonoma.

O Mac poderá reiniciar diversas vezes. Caso necessário, segure novamente a tecla Option (Alt), selecione EFI Boot e depois macOS Installer.

Não desligue o computador durante a instalação.

8.4 – Finalizar a instalação.

Quando a instalação terminar e a opção macOS Installer desaparecer, selecione Macintosh HD pelo OpenCore.

O computador deverá iniciar no macOS Sonoma.

Caso os nomes das opções sejam diferentes das imagens, consulte o suporte da FIORE antes de continuar.

Após iniciar o macOS Sonoma, prossiga para a etapa 9.

ETAPA 9 – Instalar os drivers do macOS Sonoma

Após entrar no novo sistema, abra novamente o OpenCore Legacy Patcher.

1. Clique em Post-Install Root Patch.

  1. Clique em Start Root Patching, caso existam patches necessários.

  2. Digite a senha do Mac.

  3. Aguarde a instalação dos drivers.

  1. Clique em Reboot.

  2. Aguarde o computador reiniciar.

Essa etapa é importante para o funcionamento dos componentes que dependem dos patches de compatibilidade, como Wi-Fi, vídeo e aceleração gráfica.

ETAPA 10 – Desativar as atualizações automáticas

  1. Clique no símbolo da Apple ().

  2. Entre em Ajustes do Sistema.

  3. Clique em Geral.

  4. Clique em Atualização de Software.

  5. Entre em Atualizações Automáticas.

  6. Desative o download e a instalação automática das atualizações do macOS.

Consulte a FIORE antes de realizar novas atualizações, inclusive as de segurança.

ETAPA 11 – Confirmar a instalação

  1. Clique no símbolo da Apple ().

  2. Clique em Sobre Este Mac.

  3. Confirme que o sistema instalado é o macOS Sonoma 14.

Informações importantes

  • Não é necessário utilizar pendrive.

  • Não é necessário formatar o Mac.

  • O procedimento busca preservar os arquivos e aplicativos.

  • Faça sempre um backup antes da atualização.

  • Não instale outras versões do macOS sem consultar nossa equipe.

  • Caso apareça algum erro, entre em contato com nosso suporte.
